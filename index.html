Evolution of Logic

Phase 01

Software Foundations: Art-Based 3D

My journey began in pure high-level programming. In this project, I built a 3D engine from scratch using Python Turtle, utilizing classical art perspective techniques rather than standard 3D libraries.

Phase 02

Gates & Sequential Memory

Boolean algebra provided the bridge. I started with simple combinational adders, eventually building toward sequential memory and flip-flops.

Phase 03

Shared Bus Architecture

As complexity grew, I developed a shared system bus to organize data flow—creating what I called a "Human-Driven CPU" where I manually toggled instruction steps.

Phase 04

First CPU: Harvard RISC Prototype

This prototype featured a hard Harvard split in memory, but I hit architectural walls: insufficient RAM, no subroutine support (SP), and a fixed memory layout. This discovery catalyzed the move to CISC.

Phase 05

Hardware Acceleration

The Snake Console project shifted focus toward application-specific hardware, optimizing logic for real-time performance without processor overhead.

Phase 06

The CISC Architecture

A fully programmable 8-bit machine running at 250 kHz. By moving to a CISC-based microcoded design, I solved the Phase 04 limitations. This version features a 48-bit control word, Stack Pointer support, and a robust star-topology power grid across 40+ breadboards.

Phase 07

Full-System Port: FPGA SystemVerilog SoC

To transition toward modern design methodologies and eliminate the reliability issues of loose jumper wires across 40+ breadboards, I translated the full computer system—CPU, RAM, ROM, and I/O interfaces—into synthesizable SystemVerilog on an FPGA. Running at the matched 250 kHz clock, it successfully executed the exact identical Snake machine code binary.
